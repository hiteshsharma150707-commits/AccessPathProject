PROJECT OVERVIEW

What is AccessPath?

AccessPath is a smart accessibility navigation system designed to help people find suitable routes inside colleges, hospitals and public buildings.

Users can select a starting point, destination and accessibility preference. The system uses a route-finding algorithm to suggest a suitable pathway based on the available map data.
